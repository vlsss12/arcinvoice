Compare the sources.
Expose the difference.

Run the same read-only checks against two supplied official RPC endpoints and compare chain identity, latest block, block age, and round-trip time.

◌

Each endpoint receives only eth_chainId, eth_blockNumber, and eth_getBlockByNumber. A local threshold of ≤1 block is clearly labelled, not treated as an official SLA.

Safety standard
Useful mainnet tools
should earn trust.

        
✓
Label the state clearly. Preview, unavailable, and verified are different states — users should never need to guess.
✓
Keep ownership with the user. A wallet must approve its own actions; a site should explain every request before it happens.
✓
Link to primary sources. When official Arc endpoints and explorer routes are ready, use them directly and show the destination.
